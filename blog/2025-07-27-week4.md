Hari ini adalah hari pertama saya memulai proyek Docusaurus. {/* truncate */} Setelah membaca dokumentasi resmi, saya mencoba menjalankan perintah instalasi npx create-docusaurus@latest my-website classic.

Namun, proses ini memunculkan *Error* yang cukup panjang di terminal!

{/* truncate */}

### Akar Masalah dan Solusi
Setelah saya telusuri, error tersebut (*Eresolve / Peer Dependencies*) terjadi karena versi Node.js di laptop saya terlalu usang (v14.x), sedangkan Docusaurus v3 mensyaratkan minimal Node.js v18.0.

Untuk menyelesaikannya tanpa mengganggu *environment* proyek lain di laptop, saya mempelajari dan menginstal NVM (Node Version Manager). Dengan NVM, saya bisa berpindah versi Node.js dengan perintah sederhana nvm use 20.

Setelah lingkungan Node.js diperbarui, instalasi berjalan sangat mulus dan *boilerplate* Docusaurus akhirnya berhasil dirender di localhost:3000. Langkah selanjutnya adalah mempelajari struktur foldernya!
